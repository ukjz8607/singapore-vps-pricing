## 买前必须知道的四条规则

这部分内容都在官方文档里写得比较细，但套餐页上不一定显眼。

**退款：24 小时，只限首次购买，每人一次。** 服务激活后 24 小时内可以申请全额退款，退回原支付方式，但仅限新购实例，续费订单不适用，每位用户限一次。流程是提交工单、选 Billing 类别、说明原因。到账时间按支付方式不同：支付宝和加密货币 1–3 个工作日，信用卡 5–10 个工作日。因违反服务条款被终止、已使用的账户余额、因 DDoS 被黑洞 IP 这几种情况不在退款范围内。

还有一点容易忽略：退款批准后，对应的服务器实例和数据会立即永久删除。申请之前自己先备份。

**流量超限不停机，限速到 20kb/s。** 这个策略在新加坡 VPS 里不算常见。多数商家超流量后直接停服或按 GB 高价扣费，20kb/s 基本等于不可用，但至少数据还在、也不会冒出额外账单，等新计费周期自动恢复。流量只算出站，入站免费。

**DDoS 防护分两层。** 官网口径是默认尽力而为型防护，600Gbps 高级清洗需要另购。部分测评写成“全系标配 600Gbps”，跟官网说法不一致，别把它当免费赠品。

**到期当天就暂停，没有宽限期。** 官方原文是到期日即暂停、无 grace period，数据保留但服务停止，付款后自动恢复；逾期 5 天服务终止，数据可能无法恢复。系统会提前生成续费账单并发邮件，也可以预先充余额让它自动续。不想续又不需要退款的，在后台服务列表里点 Request Cancellation，选立即取消或到期取消。

支付宝付款、24 小时退款窗口、到期暂停这三件事放在一起看，实际操作节奏是：开通当天先跑通业务，24 小时内不满意就提工单，确定长期用就充余额或改年付，别拖到到期日才发现服务已经停了。
